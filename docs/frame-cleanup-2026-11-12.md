# 표·상자 화면 정리 — 바뀌는 곳 전/후 (2026-11-12)

독립 점검이 집은 "공통 틀" 가운데 **표 칸과 국가검진 상자** ①~⑨를 화면에서만 정리했다.
`data/hospitals.json`은 **한 글자도 바꾸지 않았다** — 조사 근거는 데이터에 그대로 남는다.

- 표 칸: [`lib/publicField.ts`](../lib/publicField.ts)
- 국가검진 상자: [`lib/nationalStatement.ts`](../lib/nationalStatement.ts)
- 굵게 표시: [`components/BoldText.tsx`](../components/BoldText.tsx)

## 가리지 않기로 한 것

- `홈페이지에 미게시`처럼 **병원이 올리지 않았다**는 말(150곳 안팎). 방문자에게는
  "홈페이지를 뒤져도 없다"는 쓸모 있는 안내라 2026-11-09 점검 때도 남기기로 했다.
- `(영수증 확인 필요)`처럼 **방문자가 할 일**을 적은 괄호.
- 국가검진 상자의 `일반검진 우수기관으로 표기돼 있`(3곳). ②의 "이고·이며·으로 뒤는 버린다"
  규칙에 따라 함께 사라진다. 살리려면 ③처럼 상자 아래 한 줄로 빼야 한다 — **사용자 결정 필요.**
- 희명병원 `(병원 페이지에는 출구 번호만 있어 외부 확인으로 노선을 교차 확인)`.
  "교차 확인"은 ④ 목록에 없어 그대로 뒀다 — **사용자 결정 필요.**
